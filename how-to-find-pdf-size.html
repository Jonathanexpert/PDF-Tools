Why Checking PDF File Size Matters

PDF file size affects far more than just storage space. It determines whether your document will upload successfully, how quickly it loads for the recipient, and whether it fits within the limits set by email providers, job portals, government forms, and content management systems. Most email services cap attachments at 25 MB, many application portals cap uploads at 5–10 MB, and some forms accept files no larger than 2 MB. Knowing your PDF's exact size before you hit "send" or "upload" saves you from frustrating rejections and failed submissions.

Large PDFs also take longer to open, which matters if you're sharing documents with clients or colleagues who may be on a slower connection. A bloated PDF filled with high-resolution images or unnecessary embedded fonts can balloon from a few hundred kilobytes to tens of megabytes without any noticeable change in visual quality — which is exactly why checking file size regularly is a good habit.

How to Check PDF Size on Windows

  1. Locate the PDF file in File Explorer.
  2. Right-click the file and select Properties.
  3. Under the General tab, look for "Size" and "Size on disk."

The "Size" value is the actual data size of the file, while "Size on disk" reflects how much space it takes up based on your drive's allocation unit — the number you care about is usually the first one.

How to Check PDF Size on Mac

  1. Find the PDF in Finder.
  2. Right-click (or Control-click) the file and choose Get Info.
  3. The file size appears near the top of the info window, listed in KB, MB, or GB depending on the file.

You can also select the file and press Command + I as a shortcut to open the same Get Info panel.

How to Check PDF Size on a Smartphone

On iPhone or iPad

  1. Open the Files app.
  2. Locate your PDF, then tap and hold it.
  3. Select Info (or swipe down while selecting the file in list view) to see the size.

On Android

  1. Open your device's file manager app (such as Files by Google).
  2. Tap and hold the PDF file.
  3. Select Details or Properties from the menu to view its size.

If your phone's file manager doesn't show file details clearly, uploading the document to a browser-based tool works just as well on mobile as it does on desktop, since it doesn't rely on any particular operating system.

Checking PDF Size Inside Adobe Acrobat or Preview

If you already have the PDF open in a viewer like Adobe Acrobat Reader or Apple's Preview app, you can usually find the size without closing the document:

  • Adobe Acrobat Reader: Go to File > Properties, and check the "File Size" field under the Description tab.
  • Preview (Mac): Go to Tools > Show Inspector, and the file size is listed alongside other document details.

What to Do If Your PDF Is Too Large

Once you know your file exceeds the limit you're working with, there are a few practical ways to bring it down:

  • Compress images: High-resolution photos and scans are usually the biggest contributor to file size. Compressing them can cut file size dramatically with little visible quality loss.
  • Remove unnecessary pages: Blank pages, duplicate scans, or reference material you don't need can often be deleted before sharing.
  • Strip embedded fonts and metadata: Documents created from design software sometimes carry unused fonts or editing history that adds bulk without adding value.
  • Use a dedicated compression tool: A good PDF compressor can typically shrink a file by 50–90% while keeping text sharp and readable.
  • Split large documents: If a PDF combines multiple unrelated sections, splitting it into smaller files can make each piece easier to share.
